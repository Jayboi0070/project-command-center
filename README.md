# Project Command Center
Private, single-owner personal operating system (schedule, projects, university, research, business, reports) on GitHub Pages + Vercel + Neon PostgreSQL.

Start with **docs/DEPLOYMENT.md**. Then run `backend/tests/live-smoke.js` and follow **docs/TESTING.md**.
Also read docs/SECURITY.md (limits) and docs/BACKUP_AND_RECOVERY.md.

Status: fully written; unit tests and a mock-API browser test pass. Not yet verified against a live Neon database and Vercel deployment.
